# MultiModal_LLM

Прототип локального мультимодального RAG-сервиса для поиска и анализа документов, содержащих текст и графические элементы.

## Особенности проекта

* Модули ai_newchat.py и main.py отвечают за управление контекстом диалога и формирование промптов.
* Модуль ai_engine.py обеспечивает интеграцию с локальной ИИ-инфраструктурой Ollama.
* Обработка PDF-документов выполняется локально с помощью библиотеки Poppler и модуля pdf2image для анализа таблиц и графиков.
* Настроен файл .gitignore для исключения системного кэша Python, временных файлов Word и тяжелых бинарных зависимостей.

## Технологический стек

* Язык разработки: Python 3.11
* Оркестрация: Ollama API, модели Qwen и Llama
* Обработка PDF: Poppler, pdf2image
* Тестирование: скрипты test_inference.py и train_dataset.jsonl

## Структура папок

* main.py — инициализация сервиса
* ai_engine.py — взаимодействие с Ollama API
* ai_newchat.py — управление историей чата
* test_inference.py — скрипт проверки локального контура
* train_dataset.jsonl — тестовый датасет
* .gitignore — фильтрация временных файлов

## Инструкция по запуску

1. Запустить Ollama локально и скачать модель командой:
ollama pull qwen2.5

2. Установить зависимости проекта.

3. Запустить скрипт проверки интеграции:
python test_inference.py
